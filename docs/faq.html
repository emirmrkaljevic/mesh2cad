mesh2cad FAQ

Is mesh2cad free?

Yes. It is open source on GitHub and installs with pip install mesh2cad from PyPI.

Is the STEP file just triangles?

No. Planes, cylinders, cones, spheres and fillets are fitted and written as an exact B-rep, so holes and faces can be selected and dimensioned in CAD. If no exact fit passes, it falls back to a faceted solid and says so in the report.

How accurate is it?

Every parametric export is checked against the input mesh: maximum deviation must be at most max(4 x tolerance, 0.1 mm) and volume error at most 1%. The --report file lists the measured numbers.

Which parts work?

Mechanical parts made of planes, cylinders, cones, chamfers and simple fillets. On 6 real Original Prusa i3 MK3S parts: exact STEP for 6 of 6, editable CadQuery/OpenSCAD for 5 of 6.

Which parts fail?

Organic shapes, 3D scans and freeform (B-spline) surfaces. In the Prusa test set, y-belt-holder is refused for a parametric script because of its curved belt pocket and a base that steps down. Fillets on hole edges (torus) are not supported yet.

Can I use it from Claude Desktop, Cursor or another AI agent?

Yes. pip install "mesh2cad[mcp]" and add { "mcpServers": { "mesh2cad": { "command": "mesh2cad", "args": ["mcp"] } } } to the client config. Tools: convert, analyze, report, to_cadquery, to_openscad.

Do I need OpenSCAD installed?

Only to verify .scad output. The script is still written without it.

My STL converts badly. What now?

Open an issue on GitHub with the file. Failing real parts are the most useful input.
